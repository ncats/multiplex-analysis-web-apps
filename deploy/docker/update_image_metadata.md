# Update image metadata locally

Just as on Snowflake we would do something like:

```sql
insert into mawa_app_db.general_schema.image_metadata_table (image_id, name, tag, git_commit, environment_yaml_file, archive_compatibility_id, who_added) values 
('sha256:50d9492c8c022ef8e1d03a4a1ba631f12d8d92a2756d6304bcd825cf0b4f576a', 'mawa-frontend', '2025-11-24-v04-leandro-robert-env', '3da40cf2eaa6e80b0baf847b809aa2ab3f59f059', 'environment-leandro-compatible.yml', 'leandro-robert', 'andrewweisman');
```

whenever we push an image there, locally we want to do the analogous. However, since Docker volumes can so easily be destructed permanently using `docker compose down -v`, we want to rebuild the table every single time, just to be safe, and store the entire table contents here. That's what these instructions are for.

1. Ensure MAWA is running so that the database can be connected to. E.g.:

    ```bash
    ENV_NAME=leandro-robert ENV_PY_VER=3.12 DATE=2025-11-25 BUILD_VER=01 docker compose up
    ```

1. Connect to the database:

    ```bash
    docker exec -it postgres bash
    ```

    In the database shell:

    ```sql
    psql "postgresql://postgres:password@database:5432/app_a_app_db"
    ```

1. Drop the table completely:

    ```sql
    drop table if exists general_schema.image_metadata_table;
    ```

1. Create a new table from scratch:

    ```sql
    CREATE TABLE IF NOT EXISTS general_schema.image_metadata_table (
        id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
        image_id VARCHAR(255) UNIQUE NOT NULL,
        name VARCHAR(255),
        tag VARCHAR(255),
        git_commit VARCHAR(255),
        environment_yaml_file TEXT,
        archive_compatibility_id VARCHAR(255),
        image_added_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
        who_added VARCHAR(255)
    );
    ```

1. Add the data for the table (keep this up to date always!):

    ```sql
    insert into general_schema.image_metadata_table (image_id, name, tag, git_commit, environment_yaml_file, archive_compatibility_id, who_added) values 
    ('sha256:f6017917068b7f4904e762c5b10429979334f02c175505c94a9704b3961826ac', 'mawa-frontend', '2025-11-25-v01-leandro-robert-env', '3011f84e3a6cd2f06d6142534de5a67820d5269e', 'environment-leandro-compatible.yml', 'leandro-robert', 'andrewweisman');
    ```

1. Check that it worked:

    ```sql
    select * from general_schema.image_metadata_table;
    ```
